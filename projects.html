Fragrance Library

A web application for organizing a personal fragrance collection, discovering fragrances, and tracking what it would cost to buy each bottle today. Built by Miguel A. De Jesus as a Polo Studios project.

  • JavaScript
  • Supabase
  • Web Applications
  • Product Development
Open Fragrance Library ↗View source on GitHub ↗

Available in the app

  • Username sign-up and private collections saved across devices.
  • Separate collection and wishlist views.
  • A searchable fragrance catalog with brand filters and reviewed product photos.
  • Exact bottle details: concentration, size, quantity, and standard or tester packaging.
  • Replacement-value estimates from matching seller offers, plus collection backup exports.

Project dates

First repository commit: October 13, 2026.
Status: Ongoing. Final completion date is not set.

Current stage

The app is live and under active development. Seller prices are entered manually; automatic market-price feeds and affiliate integrations are planned. Missing prices stay unknown rather than being shown as zero.
