The application

Two roles. One rental system.

Discover & queue

Customers browse available movies, search by genre, read descriptions, and add or remove titles from their rental queue.

  • Movie metadata and poster images.
  • Genre-based catalog browsing.
  • Availability checks before queuing a movie.

Rent & return

Rental records connect customers to movies throughout the rental lifecycle, with separate current and past views.

  • Current rentals and returned-movie history.
  • Watched status for rented movies.
  • Administrator controls for dispatch and return registration.

Manage the catalog

Administrators maintain movie information and review customers through dedicated pages.

  • Add and edit titles, genres, descriptions, and posters.
  • Deactivate a movie with an availability flag.
  • Retain existing records when a title leaves the active catalog.

A connected experience

The rental lifecycle.

  1. Browse

    Explore active titles and open a movie’s details.

  2. Queue

    Choose available movies and manage the customer queue.

  3. Dispatch

    An administrator sends the next eligible queued movie.

  4. Return

    Register the return and retain the rental history.

Engineering foundations

Pages, application logic, and data.

The project separates the JSP interface, Java application classes, and relational records into three cooperating layers.

01 / PRESENTATION

HTML & JSP

Customer and administrator pages present the catalog, forms, queues, and rental lists. Session attributes support the sign-in and navigation flow.

02 / APPLICATION

Java & JDBC

Java classes handle movie management, customer and rental operations, database connectivity, and database-driven page permissions.

03 / STORAGE

MySQL

Related tables store movies, customers, queues, rentals, roles, page permissions, and allowed navigation paths.

An availability flag hides inactive titles from catalog queries while preserving movie records and their relationships to rental history.
